# Homework 20.1: Проектирование БД и работа с таблицами (DDL)

## Описание
Практическое задание по Data Definition Language (DDL) в PostgreSQL.
Выполнение SQL-запросов для создания, изменения структуры таблиц и управления данными.

## Структура проекта
homework-20.1/
├── alter_student.sql # Запросы для таблицы student
├── alter_northwind.sql # Запросы для БД Northwind
└── README.md # Инструкция по выполнению


## Требования
- PostgreSQL (установлен и запущен)
- pgAdmin (интерфейс на русском языке)
- PyCharm (для редактирования .sql файлов)

## Инструкция по выполнению

### 1. Настройка pgAdmin
1. Откройте pgAdmin
2. Подключитесь к серверу PostgreSQL
3. Для задания `alter_student.sql`: создайте новую базу данных или используйте существующую
4. Для задания `alter_northwind.sql`: убедитесь, что база данных `Northwind` существует и содержит таблицы `products`, `order_details`

### 2. Выполнение alter_student.sql
1. В PyCharm откройте файл `alter_student.sql`
2. Скопируйте запросы по одному
3. В pgAdmin откройте **Инструменты запросов** (Query Tool)
4. Вставьте запрос и нажмите **Выполнить** (F5)
5. Проверьте результат в панели вывода
6. Повторите для всех 7 заданий

### 3. Выполнение alter_northwind.sql
1. В PyCharm откройте файл `alter_northwind.sql`
2. Убедитесь, что подключены к базе `Northwind`
3. Выполняйте запросы последовательно через **Инструменты запросов** в pgAdmin
4. Особое внимание на задание 4: перед удалением товаров снимается ограничение внешнего ключа

## Примечания
- Все запросы пишутся в .sql файлы в PyCharm
- Проверка выполняется только в pgAdmin
- Не выполняйте SQL-код в терминале PyCharm (PowerShell не поддерживает SQL)
- Задание 4 в alter_northwind.sql требует осторожности: удаление foreign key может повлиять на целостность данных
